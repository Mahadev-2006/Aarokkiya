# Aarokkiya (ஆரோக்கியம்) 🩺
**Agentic AI Healthcare Assistant for Universal Triage & Support**

Aarokkiya is a modular, agentic AI-powered healthcare web application built for the 2026 B.Tech Final Year project. It utilizes a **Multi-Agent System (MAS)** architecture to provide real-time medical insights, report analysis, and doctor communication.

---

## 🚀 Key Features
- **Symptom Checker tool**: Real-time triage using NIH Clinical Tables API.
- **Medicine Explanation tool**: Comprehensive drug data via RxNorm & OpenFDA.
- **Clinical Summary Generator tool**: Evidence-based brief generation using Llama 3.2 & PubMed.
- **Hospital Locator tool**: Location-based care finding using OpenStreetMap.
- **Doctor Communication section**: Privacy-first human consultation via **Arattai (Zoho)**.

## 🛠️ Technical Stack
- **Core LLM**: Llama 3.2 (Local execution via HP Victus RTX 3050)
- **Framework**: CrewAI (Multi-Agent Orchestration)
- **UI**: Streamlit (Python-based Web Interface)
- **Knowledge Base**: On-the-fly API Retrieval (No local data storage required)
